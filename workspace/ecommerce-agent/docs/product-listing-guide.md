## 📸 商品拍摄

### 拍摄准备

#### 设备准备
- **手机**: iPhone或华为等高端手机（像素1200万以上）
- **背景**: 白色背景布（或干净的白墙）
- **光源**: 自然光最佳，或LED补光灯
- **支架**: 手机支架（保持稳定）

#### 拍摄环境
- 光线充足（避免阴影）
- 背景整洁（白色或灰色）
- 商品干净（去除灰尘）

### 拍摄要求

#### 主图（第一张）
- ✅ 白底、清晰、突出商品
- ✅ 尺寸：800x800像素或以上
- ✅ 不添加文字或水印
- ✅ 商品占图片70%以上
- ❌ 不要拼接图
- ❌ 不要加边框

#### 详情页图片
- 多角度展示（正面、侧面、背面）
- 尺寸对比（放硬币或手机）
- 细节特写（材质、做工）
- 使用场景（实际使用）

#### 拍摄角度
1. **正面图**: 商品正面全貌
2. **侧面图**: 商品侧面展示
3. **背面图**: 商品背面展示
4. **细节图**: 放大细节（如材质、接口）
5. **对比图**: 放对比物（如硬币、手机）
6. **使用图**: 实际使用场景

### 拍摄技巧

#### 光线技巧
- 使用自然光（窗边拍摄）
- 避免强光直射
- 避免阴影和反光
- 必要时使用LED补光灯

#### 构图技巧
- 商品居中
- 留白适当
- 角度端正
- 对焦清晰

#### 修图技巧
- 调整亮度（不过度）
- 调整对比度（清晰即可）
- 裁剪图片（突出商品）
- 不要过度美化（失真）

### 常见错误

#### ❌ 拍摄常见错误
1. 光线不足（照片暗淡）
2. 背景杂乱（分散注意力）
3. 商品歪斜（看起来不专业）
4. 对焦不清（模糊）
5. 过度美化（失真）

## ✍️ 商品标题优化

### 标题结构

#### 标准结构
```
[品牌/卖点] + [核心关键词] + [属性词] + [场景词] + [修饰词]
```

#### 标题示例
```
"2024新款 手机壳 苹果15保护套 硅胶防摔 简约百搭"
"ins风 杯子 玻璃水杯 带盖带勺 家用办公 时尚简约"
"无线蓝牙耳机 降噪挂耳式 适用安卓苹果 运动跑步"
```

### 关键词获取

#### 方法1：淘宝搜索框
1. 在淘宝搜索框输入商品名
2. 查看下拉推荐词
3. 记录高频关键词

#### 方法2：竞品标题
1. 搜索同类商品
2. 查看销量高的商品标题
3. 提取关键词

#### 方法3：生意参谋（付费）
1. 淘宝生意参谋工具
2. 查看关键词搜索量
3. 选择高搜索量词

### 标题优化技巧

#### 优化原则
1. **包含核心关键词**（必选）
2. **字数控制**（30字以内）
3. **突出卖点**（防摔、无线等）
4. **避免堆砌**（不要重复关键词）

#### 优化步骤
1. 确定核心关键词（如"手机壳"）
2. 添加属性词（如"苹果15"、"硅胶"）
3. 添加卖点词（如"防摔"、"无线"）
4. 添加场景词（如"运动"、"家用"）
5. 调整语序，通顺即可

### 标题避坑

#### ❌ 避免的标题
1. 过长（超过30字）
2. 关键词堆砌（重复词语）
3. 添加违规词（如"第一"、"官方"）
4. 包含无关词（如"免费"、"包邮"等）

#### ✅ 优质标题特点
1. 简洁明了（一眼看懂）
2. 包含卖点（突出优势）
3. 字数适中（20-30字）
4. 语序通顺（不生硬）

## 📄 商品详情页制作

### 详情页结构

#### 第1屏：首屏吸引
- 商品主图（大图展示）
- 核心卖点（3-5个，用图标+文字）
- 价格信息（原价、优惠价）
- 活动信息（优惠券、满减）

#### 第2屏：商品介绍
- 商品描述（详细介绍）
- 规格参数（尺寸、材质、重量）
- 适用范围（哪些人适合）
- 使用说明（如何使用）

#### 第3屏：图文展示
- 多角度图片（正面、侧面、背面）
- 细节展示（材质、做工）
- 使用场景（实际使用）
- 效果展示（前后对比）

#### 第4屏：购买引导
- 适用人群（谁适合买）
- 购买理由（为什么要买）
- 售后保障（7天退换、正品保障）
- 紧迫感（限时优惠、库存紧张）

### 详情页制作工具

#### 手机端工具
- **美图秀秀**: 简单易用，适合新手
- **醒图**: 模板丰富
- **黄油相机**: 贴纸多

#### 电脑端工具
- **Photoshop**: 专业工具（需要学习）
- **Canva**: 在线设计（模板丰富）
- **稿定设计**: 中文模板多

#### 制作步骤
1. 确定详情页结构
2. 准备图片和文字
3. 使用工具排版
4. 预览效果
5. 导出为图片

### 详情页优化技巧

#### 优化原则
1. **首屏吸引**（前3秒决定去留）
2. **图文并茂**（不要全是文字）
3. **卖点突出**（让客户一眼看到）
4. **信任背书**（售后保障、好评）

#### 优化技巧
- 使用图标（让卖点更直观）
- 使用对比（前后对比、竞品对比）
- 使用场景（让客户有代入感）
- 使用数据（如"10万+好评"）

## 💰 价格策略

### 定价方法

#### 成本定价法
```
售价 = 成本 + 利润
```

**示例**：
- 进货价：50元
- 运费：5元
- 包装费：2元
- 目标利润：20元
- 售价：77元

#### 竞品定价法
```
售价 = 竞品均价 × (1 ± 调整系数)
```

**示例**：
- 竞品均价：100元
- 调整系数：0.95（低于竞品5%）
- 售价：95元

#### 心理定价法
```
售价 = 整数 - 1元 或 9元结尾
```

**示例**：
- 实际售价：100元
- 心理定价：99元
- 优势：看起来更便宜

### 使用本系统辅助定价

#### 三档定价方案
1. **保守定价**（低于竞品5%）
   - 适合：新品上市
   - 目标：快速获取市场

2. **正常定价**（目标利润率）
   - 适合：常规商品
   - 目标：稳定利润

3. **激进定价**（高于竞品5%）
   - 适合：优势商品
   - 目标：高利润

#### 使用步骤
1. 在本系统输入商品信息
2. 查看定价建议
3. 对比三档定价
4. 选择适合的定价

### 价格优化

#### 促销价格
- **限时折扣**：8-9折（7天）
- **满减活动**：满100减20
- **优惠券**：满50减5

#### 价格调整
- 新品：略低于市场价
- 成熟期：参考市场价
- 清仓期：低于成本价（快速清仓）

## 📦 规格设置

### 常见规格分类

#### 颜色
- 黑色、白色、红色、粉色、蓝色...
- 使用色块图片展示

#### 尺寸
- S、M、L、XL、XXL
- 使用尺码表

#### 型号
- iPhone15、iPhone14、iPhone13
- 使用对应图片

#### 套餐
- 标准版（商品）
- 豪华版（商品+配件）
- 超值版（商品+配件+服务）

### 规格设置技巧

#### 规格数量
- 建议：3-5个规格
- 不要太多（客户选择困难）
- 不要太少（缺乏竞争力）

#### 规格价格
- 不同规格不同价格
- 热门规格优惠价
- 套餐组合提客单价

#### 规格展示
- 使用图片（色块、型号图）
- 使用文字（清晰标注）
- 使用对比（让客户明白差异）

## 🎯 上架优化技巧

### 上架时间

#### 最佳时间
- **上午**：9:00-11:00（上班时间）
- **晚上**：19:00-21:00（下班后）
- **周末**：流量较大

#### 避免时间
- **深夜**：23:00-6:00（流量小）
- **工作日中午**：12:00-14:00（休息）

### 批量上架

#### 上架数量
- 新手：每次5-10个
- 进阶：每次10-20个
- 不要一次上架太多（容易混乱）

#### 上架间隔
- 同类商品：隔天上架
- 不同类商品：可以一起上架

### 上架后优化

#### 7天观察
- 查看点击率
- 查看转化率
- 查看收藏量

#### 优化调整
- 点击率低 → 优化标题和主图
- 转化率低 → 优化价格和详情页
- 收藏量低 → 优化卖点

## 📊 数据监控

### 关键指标

#### 展现量
- 展现次数
- 排名位置

#### 点击率
- 点击率 = 点击量 / 展现量
- 目标：>3%

#### 转化率
- 转化率 = 订单量 / 点击量
- 目标：>5%

#### 客单价
- 客单价 = 销售额 / 订单量
- 目标：根据商品定价

### 数据分析

#### 每日查看
- 淘宝卖家版APP
- 查看商品数据

#### 每周分析
- 导出数据
- 对比分析
- 优化调整

## 🆘 常见问题

### Q1: 上架多久能出单？
A: 新品上架后，通常需要7-30天才能出单，取决于商品竞争力。

### Q2: 可以频繁修改标题吗？
A: 可以，但不要频繁修改，建议1-2周优化一次。

### Q3: 主图可以修改吗？
A: 可以，随时可以修改，不影响权重。

### Q4: 价格可以频繁调整吗？
A: 可以，但不要频繁调整，建议参考本系统的定价建议。

### Q5: 如何提高点击率？
A: 优化标题和主图，突出卖点。
