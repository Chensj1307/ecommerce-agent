## 📋 开店前准备

### 需要准备的资料
- ✅ 身份证（正反面照片）
- ✅ 银行卡（用于提现）
- ✅ 手机号（用于注册和验证）
- ✅ 支付宝账号（用于收款）

### 硬件设备
- 📱 智能手机（iOS或Android均可）
- 💻 电脑（可选，用于批量操作）

### 保证金
- 金额：1000元
- 性质：可退还
- 退款：关店时申请退还

## 🚀 开店步骤详解

### 步骤1：下载APP

#### 方法1：手机下载
```
打开应用商店
搜索"淘宝卖家版"
下载安装
```

#### 方法2：电脑访问
```
访问：https://sell.taobao.com
扫码下载
```

---

### 步骤2：注册淘宝账号

#### 如果已有淘宝账号
- 直接登录即可
- 跳转到步骤3

#### 如果没有淘宝账号
1. 打开淘宝卖家版APP
2. 点击"注册"
3. 输入手机号
4. 获取验证码
5. 设置密码
6. 完成注册

---

### 步骤3：实名认证

#### 认证流程
1. 登录淘宝卖家版
2. 进入"我的"页面
3. 点击"实名认证"
4. 上传身份证正反面照片
5. 进行人脸识别
6. 等待审核（通常1-5分钟）

#### 注意事项
- 身份证照片要清晰
- 确保身份证在有效期内
- 照片上不要有反光

---

### 步骤4：绑定支付宝

#### 绑定流程
1. 进入"支付宝管理"
2. 点击"绑定支付宝"
3. 确认手机号
4. 输入验证码
5. 绑定成功

#### 支付宝用途
- 收款
- 缴纳保证金
- 提现

---

### 步骤5：提交开店申请

#### 提交流程
1. 进入"开店"页面
2. 选择店铺类型：
   - **个人店铺**（推荐）：适合新手
   - **企业店铺**：适合规模化运营

3. 填写店铺信息：
   - 店铺名称（2-20个字符）
   - 店铺类目（选择主营类目）
   - 经营地址（实际经营地址）

4. 同意开店协议

5. 提交审核

#### 审核时间
- 通常：1-3个工作日
- 最快：几小时
- 最慢：5个工作日

---

### 步骤6：缴纳保证金

#### 缴纳流程
1. 开店审核通过后
2. 进入"保证金管理"
3. 选择缴纳金额：1000元
4. 选择支付方式：支付宝
5. 确认支付

#### 保证金说明
- 金额：1000元
- 可退还：关店时申请退还
- 用途：违规罚款、售假罚款
- 冻结：严重违规时可能冻结

---

### 步骤7：店铺设置

#### 基本设置

**店铺名称**
```
格式：XX小店 / XX优选 / XX家居
示例：时尚家居小店 / 数码配件优选
```

**店铺头像**
- 尺寸：200x200像素
- 格式：JPG/PNG
- 建议：简洁的Logo或图案

**店铺简介**
```
示例：
本店主营数码配件，品质保证，售后无忧。
欢迎关注收藏，不定时优惠活动。
```

**店招**
- 尺寸：950x150像素
- 用途：店铺横幅广告
- 可以设计：店铺Slogan、活动信息

## 📦 首批商品上架

### 上架流程

#### 第一步：拍摄商品照片
1. 准备拍摄背景（白色背景布）
2. 使用智能手机拍摄
3. 拍摄多角度照片
4. 确保照片清晰

#### 第二步：制作商品详情页
1. 准备商品介绍
2. 制作图片（可用美图秀秀）
3. 组合成详情页
4. 检查排版

#### 第三步：填写商品信息
1. 进入"发布商品"
2. 选择类目
3. 填写商品标题
4. 上传主图（5-9张）
5. 填写详情页
6. 设置价格
7. 设置库存
8. 设置规格
9. 发布商品

### 首批上架建议
- **数量**：5-10个商品
- **品类**：集中在1-2个品类
- **质量**：确保有库存、质量好

## ⚠️ 注意事项

### 开店注意事项
1. **实名认证**必须完成，否则无法开店
2. **保证金**必须缴纳，否则无法上架商品
3. **个人信息**要真实有效
4. **店铺名称**不能违规（如：品牌、官方等）

### 上架注意事项
1. **图片**必须真实，不能盗图
2. **价格**要合理，参考市场价
3. **描述**要真实，不能虚假宣传
4. **库存**要准确，不能超卖

### 违规后果
- 下架商品
- 扣除保证金
- 限制开店权限
- 严重违规封店

## 🆘 常见问题

### Q1: 开店需要营业执照吗？
A: 个人店铺不需要营业执照，企业店铺需要。

### Q2: 保证金可以退吗？
A: 可以退。关店时申请退还，通常7个工作日到账。

### Q3: 可以一个人开多个店铺吗？
A: 一个身份证可以开一个淘宝店铺。

### Q4: 开店后必须马上卖东西吗？
A: 不需要，可以先上架商品，熟悉流程后再正式运营。

### Q5: 可以卖什么商品？
A: 除违禁品（如烟草、酒类、假货等）外，大部分商品都可以卖。

### Q6: 如何联系客服？
A: 淘宝客服热线：9510211
